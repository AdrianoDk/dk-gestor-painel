# Dk Gestor Painel

Monte um aplicativo com o nome Dk Gestor Franquias.

Sendo um dashboard de consulta às informações de valores recebidos, despesas, quantidade de matrículas, quantidade de cancelamentos, quantidade de alunos, tendo filtros fixo de dia atual, ultima semana, últimos 25 dias e um campo para informar o período manualmente.

Deve ser permitido informar mais de um token diferente, para consultar unidades diferentes, com um ranking dinâmico de colocação com base nas informações e período filtrados.

Pensado como um dashboard para o franqueador consultar as informações, adicionando o token de cada unidade pertencente à franquia, uma interface simples que seja de fácil visualização e entendimento, pensando na experiência do usuário, tanto na visualização pelo desktop como por um celular.

Os tokens das unidades devem ficar salvos no navegador do dispositivo utilizado, dispensando o login e mantendo a segurança.

É necessário ter o campo para informar os tokens de cada unidade.

Além da visualização geral é possível ter um quadro a direita para visualizar dados de cada unidade e uma calculadora de royalties.
